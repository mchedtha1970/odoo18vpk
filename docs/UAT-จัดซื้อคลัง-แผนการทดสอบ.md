โรงพยาบาลวชิระภูเก็ต · Odoo 18  
เวอร์ชันเอกสาร: 1.1 · วันที่: 10 กันยายน 2569  
ใช้คู่กับใบบันทึกผล `UAT-จัดซื้อคลัง-ใบบันทึกผล.xlsx`

แผนนี้ทดสอบวงจร **ขอซื้อ (PR) → จัดซื้อ (PO) → รับของเข้าคลัง → ตัดสต็อก**  
การจองงบ / คงเหลืองบ ใช้คู่กับแผน `UAT-งบประมาณ-แผนการทดสอบ.md` ชุด D

## 1. วัตถุประสงค์

1. ให้หน่วยงานสร้างใบขอซื้อได้ ออกเลขอัตโนมัติ เลือกคลังรับของได้เฉพาะประเภท Receipt
2. ให้พัสดุ/จัดซื้อ สร้างและยืนยันใบสั่งซื้อจาก PR ที่อนุมัติแล้ว
3. ให้งานคลังรับของเข้าคลัง ตรวจสต็อก และจ่ายของออกได้ถูกต้อง
4. ตรวจกรณียกเลิก รับบางส่วน และงบไม่พอ ว่าระบบกันได้
5. เก็บหลักฐานผ่าน/ไม่ผ่าน สำหรับ Go-Live

## 2. ขอบเขต

### อยู่ในขอบเขต

- ใบขอซื้อ (Purchase Request)
- ใบสั่งซื้อ / ใบสั่งจ้าง (Purchase Order)
- การรับสินค้าเข้าคลังจาก PO (Receipt)
- สต็อกคงเหลือ การโอนภายในคลัง การจ่ายของ
- สิทธิ์หน่วยงาน พัสดุ งานคลัง
- การเช็คงบบน PR (เชื่อมแผนงบประมาณ)

### อยู่นอกขอบเขตรอบนี้

- แผนงบประมาณตั้งต้นปี (ใช้แผน UAT งบประมาณ)
- e-GP / ประกาศประกวดราคาเต็มรูปแบบ
- การตรวจรับกรรมการและการแต่งตั้งคณะกรรมการ (ทดสอบแยกถ้าเปิดใช้จริง)
- การนับสต็อกสิ้นปีแบบเต็มรูปแบบ (นับเป็นเคส P2)

## 3. สิ่งที่ต้องเข้าใจก่อนทดสอบ

ลำดับเอกสารห้ามสลับ

| ขั้น | เอกสาร | ผู้ทำ | ผลที่เกิด |
|---|---|---|---|
| 1 | ใบขอซื้อ (PR) | หน่วยงาน | ระบุของที่ต้องการ เช็คงบ ส่งอนุมัติ |
| 2 | ใบสั่งซื้อ (PO) | พัสดุ / จัดซื้อ | ผูกผู้ขาย ราคายืนยันคำสั่งซื้อ |
| 3 | ใบรับสินค้า (Receipt) | งานคลัง | ของเข้าคลัง สต็อกเพิ่ม |
| 4 | ใบตั้งเจ้าหนี้ | การเงิน | ตัดงบเป็นใช้จริง (ทดสอบในแผนงบ) |

กติกาที่ผู้ทดสอบต้องจำ

- เลขที่ PR ออกอัตโนมัติตอนบันทึก รูปแบบ `PR` + ปี พ.ศ. 2 หลัก + เดือน + เลขวิ่ง 3 หลัก เช่น `PR6908001`
- ประเภทการรับสินค้าบน PR เลือกได้เฉพาะ **Receipts** ของคลัง ไม่โชว์ Internal Transfers / Delivery Orders / Manufacturing
- ส่ง PR แล้วระบบจองงบ (ถ้าเปิดเช็คงบ)
- ยืนยัน PO แล้วยอดย้ายเป็นผูกพัน
- รับของเข้าคลังแล้วจำนวนในคลังต้องเพิ่มตามที่รับ
- รับของได้ไม่เกินจำนวนที่สั่งใน PO

## 6. เกณฑ์เข้าทดสอบ / ออกจากทดสอบ

### เข้าทดสอบได้เมื่อ

- มีบัญชีหน่วยงาน พัสดุ งานคลัง
- มีสินค้าคุมสต็อกอย่างน้อย 1 รายการ
- มีคลังและประเภท Receipt ของคลังนั้น
- มีผู้ขายอย่างน้อย 1 ราย
- มีวงเงินงบสำหรับซื้อวัสดุ (ถ้าทดสอบเช็คงบ)

### ผ่านรอบ UAT เมื่อ

- เคส P1 ในชุด A–E ผ่านทั้งหมด
- ไม่มี Blocker เช่น สร้าง PR ไม่ได้, ยืนยัน PO ไม่ได้, รับของแล้วสต็อกไม่เพิ่ม
- ผู้แทนหน่วยงาน พัสดุ งานคลัง ลงนามท้ายเอกสาร

### ระดับความรุนแรง

| ระดับ | ความหมาย | ตัวอย่าง |
|---|---|---|
| Blocker | วงจรหลักใช้ไม่ได้ | บันทึก PR ไม่ได้, รับของแล้วสต็อกไม่ขึ้น |
| Major | ใช้ได้แต่ผิดกติกา | เลือกคลังแบบ Delivery ได้, รับของเกิน PO ได้ |
| Minor | ใช้ต่อได้แต่สับสน | ชื่อเมนูไม่ชัด, ข้อความ error ภาษาไม่ครบ |
| Cosmetic | สวยงาม | สี ระยะ ฟอนต์ |
